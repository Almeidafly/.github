# Almeidafly

Open experiments in robots, ternary computing and browser automation, built in New Bedford, MA.

## Projects

- [byte-tree](https://github.com/Almeidafly/byte-tree): ternary byte tree, 1 block to 3 to 9, one computer plus 8 data bits per byte, recursive.
- [byte-tree-quantum](https://github.com/Almeidafly/byte-tree-quantum): quantum package for the byte tree.
- [x-robot](https://github.com/Almeidafly/x-robot): approval-gated browser robot running the 8-step Lex loop.
- [browser-check](https://github.com/Almeidafly/browser-check): open a URL in Chromium, run safe read-only checks, get a JSON and markdown report.
